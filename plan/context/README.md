# Context from other chats

Drop exports or pasted excerpts of past conversations here. The relocation-grad-advisor agent reads every file in this folder before answering.

Naming: `YYYY-MM-DD-<topic>.md`, for example `2026-09-01-program-shortlist.md`.

Each file should start with a one-line summary of what the chat was about, then the relevant content. Decisions made in these chats override nothing in `plan/`; the agent will ask before changing recorded state that conflicts with a context file.
